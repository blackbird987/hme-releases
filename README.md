# Halo Momentum Evolved (Windows)

Halo: Combat Evolved with Apex Legends style movement. This page only hosts the Windows download.

## Install

1. Download `HaloMomentumEvolved-v0.0.10-windows.zip` (the newest version's zip) from the [latest release](https://github.com/blackbird987/hme-releases/releases/latest).
2. Unzip it into a folder of its own (for example `C:\Games\HME`).
3. Run `halo.exe`. Windows may warn that the app is unrecognised: click "More info", then "Run anyway". If the firewall asks, allow it (private and public networks), or online play cannot connect.

## Maps

The game needs Halo's multiplayer maps. On its first start it looks for them:

- With Halo PC or Halo Custom Edition installed, choose "Make the maps". It takes about a minute and a half.
- Without either, ask whoever invited you for their `maps` folder and put it next to `halo.exe`.

## Join a friend

1. Your friend hosts: Multiplayer, Create Game, Internet. The game copies an invite link (`hme://join/...`) to their clipboard, and they send it to you.
2. Copy the link, then click into your game (or open the link). It connects to your friend, and their game shows under Multiplayer, System Link. Join it there.

With the Discord app running on both PCs, you can also join with Discord's invite button instead.

Both players need the same version of the game: download the latest release whenever your friend updates.
